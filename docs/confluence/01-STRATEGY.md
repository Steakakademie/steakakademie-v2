## Strategie: Vorsprung-Verteidigung (4 Burggräben)

> Befund: Steakakademie ist Online-Vorreiter der Grillbildung — die SERPs für „Grillkurs/Grillschule" sind von **Präsenz-Anbietern** belegt (Weber, Grillfürst, Santos), Online ist die Lücke. „Erster" ist KEIN Schutz. Vorsprung halten = Burggraben bauen.

1. **Proprietäre Tiefe = Pitmaster-Doktrin.** Experten-geprüfte Regeln (Temperaturen, Rasten, Cut-Dicke). Stärkster Graben. Nicht von generischer KI kopierbar.
2. **Compounding-Content-Maschine.** Glossar- + Rezept-Pipeline + eigene FLUX-Bilder, katalog-aligned, automatisch wachsend — Tempo MIT Qualitäts-Gate.
3. **GEO / Structured-Data First-Mover.** In KI-Antworten **zitiert** werden, nicht nur ranken. Lückenloses Schema + präziseste Werte.
4. **Proprietäre Daten-Schleife.** Steak-Beichte-Diagnosen + Mein-Protokoll-Pläne + Fleischpass = Daten + Personalisierung + Wechselkosten.
5. **Distinktive Marke „Steakakademie".** Eigenname statt Gattungsbegriff → besetzt die Marken-SERP allein. NIE in „Grillakademie" umbenennen.

**Reale Gefahr:** nicht die Offline-Schule — sondern Weber/Grillfürst (Marke+Budget) falls sie online gehen, oder KI-Content-Flut. Agent 7 muss „Präsenz-Player geht online" früh melden.
